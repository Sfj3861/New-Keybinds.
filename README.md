# New Keybinds

An Android-focused Geometry Dash mod adding keyboard shortcuts and a dedicated popup interface.

## Milestone 0.4.0
- Added a dedicated New Keybinds popup overview with Gameplay, Editor and Navigation sections.
- Added a New Keybinds entry to the ModsLayer menu.
- Existing gameplay and editor keybind prototype remains in place.

## Existing keyboard prototype
Gameplay: P1/P2 jump, place/delete practice checkpoint, restart.
Editor: W/A/S/D movement and Q/E rotation shortcuts.

## Planned
- Dedicated binding editor and capture UI, multiple bindings per action, conflict detection and profiles.
- Navigation actions.
- Controller profiles and mapping.
- Mobile Smart Controls.
- Localization: English, Spanish, French and Russian.

## Target
- Geometry Dash Android 2.2091
- Geode SDK 6.0.0
- C++23

The interface milestone has not yet been validated on-device. CI compilation and runtime compatibility must be confirmed.

## Build
Requires Geode SDK and Android NDK. Configure GEODE_SDK and build for Android64.
