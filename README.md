# New Keybinds

An Android-focused Geometry Dash mod that adds configurable keybinds.

## Current status

**Prototype 0.1.0**

- Geode keybind settings for Player 1 and Player 2 jump inputs.
- Initial gameplay event routing through `UILayer`.
- Android target: Geometry Dash 2.2091.
- Editor keybinds and additional gameplay actions are not implemented yet.

## Build

Requires the Geode SDK and Android NDK. Configure the `GEODE_SDK` environment variable, then build for the Android architecture supported by your device using the Geode CLI.
